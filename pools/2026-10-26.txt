#@ constraints
+ Every action works without a mouse.
+ Tap targets are at least 44 pixels tall.
+ Text stays legible at 200 percent zoom.
+ Every action gives immediate visible feedback.
+ Changing labels never shift the main control.
+ Reduced motion keeps every state usable.
+ Focus stays visible on both light and dark surfaces.
+ A failed action always offers a useful next step.
+ No information relies only on color.
+ Every drag action has a button or key alternative.
+ A pending action can finish without a layout jump.
+ An empty state offers one clear action.
+ A panel returns focus to its trigger on close.
+ Use one consistent spacing scale.
+ Long labels wrap without hiding the action.
+ The first frame shows the useful component.
+ Every selected item has a non-color state marker.
+ Repeated input cannot queue duplicate work.
+ The component fits a narrow phone frame.
+ Light and dark modes keep equal visual hierarchy.
+ Use one accent only for state or action.
+ Icons have a consistent stroke weight.
+ No motion delays access to content.
+ The component remains useful with sound off.
+ A completed action can be tried again.
+ Every field keeps its label visible.
+ Disabled controls explain their reason when needed.
+ Error text stays beside the relevant action.
+ The useful result stays visible after motion stops.
+ A loading state preserves the final content size.
+ An open overlay closes with the escape key.
+ Space and enter trigger focused buttons.
+ Keyboard focus follows the visible reading order.
+ Use realistic short sample content.
+ Hidden pages stop all animation work.
+ Idle components stop their render loop.
+ The main action uses a clear verb.
+ Borders and shadows share one visual weight.
+ The state remains correct during rapid input.
+ Use tabular figures where values change.
+ No control depends on hover alone.
+ The component has a clear reset or reverse action.

Save notice: a toast for a project editor that confirms a save and then clears without blocking the work.
Item quantity: a stepper for a shopping cart that changes item count and updates the total.
Product rating: a rating control for a shop that lets someone select a score and change it before saving.
Workspace search: a search field for a team app that filters project names and shows when nothing matches.
Booking date: a date picker for an appointment prototype that selects an available day and shows the choice.
Upload progress: a progress ring for a media tool that shows how much of a file has uploaded and when it finishes.
Result pages: pagination for a content library that moves through results and marks the current page.
Folder trail: breadcrumbs for a file browser that show the current folder and let someone return to a parent.
Copy invite: a copy button for a team app that copies an invite link and confirms success.
Password reveal: a password field for a signup prototype that switches between hidden and visible text without losing input.
Content tags: a tag input for a publishing tool that adds, edits, and removes labels from a draft.
Brand color: a color picker for a site builder that changes the accent color in a live preview.
Loading preview: a skeleton for a project gallery that holds the card layout while sample content loads.
First project: an empty state for a workspace that explains the next action and lets someone create a first project.
Launch countdown: a countdown for a product launch page that shows time remaining and changes state when the launch arrives.
View switch: a segmented control for a project library that switches between list, grid, and compact views.
Task selection: a checkbox for a task list that selects one task or shows a partly selected group.
Board order: a reorder list for a planning board that moves tasks and makes their new order clear.
Team members: an avatar stack for a project header that shows collaborators and reveals the people hidden in the count.
Unread count: a badge for an inbox that updates when messages arrive or someone marks them read.
Activity trend: a sparkline for a product dashboard that shows a short activity history and reveals a selected value.
Undo edit: an undo control for a canvas editor that restores the previous change and shows what came back.
