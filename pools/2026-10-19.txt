#@ tasks
+ Toggle: a switch with two states that shows how far it travelled to get there.
+ Slider: a range control that feels the weight of the value it holds.
+ Button: one press that confirms itself without a second screen.
+ Loader: a wait that shows honest progress instead of a spin.
+ Tooltip: a hint that appears only when the hand hesitates.
+ Tabs: a few panels that trade places without losing the reader's place.
+ Accordion: sections that open one at a time and remember which was last.
+ Dialog: a small window that asks one question and then steps aside.
+ Toast: a short notice that arrives, is read, and leaves on its own.
+ Stepper: a number control that counts up and down with a steady hand.
+ Rating: a score from one to five given with a single gesture.
+ Search field: a box that narrows a short list as each letter lands.
+ Date picker: choosing one day without a full calendar in the way.
+ Progress ring: a circle that fills as one task moves toward done.
+ Pagination: moving through many pages while always knowing where you are.
+ Breadcrumb: the trail back up from a deep page.
+ Copy button: one tap that copies a line of text and proves it worked.
+ Password field: a hidden word that shows its strength as it is typed.
+ Tag input: words typed, kept as small pieces, and removed one by one.
+ Colour swatch: picking one colour from a small, honest palette.
+ Skeleton: the shape of content before the content arrives.
+ Empty state: what a list shows when there is nothing in it yet.
+ Countdown: a timer that runs down to one moment and marks it.
+ Segmented control: three choices side by side, one always chosen.
+ Checkbox: a mark that can be set, cleared, or left half done.
+ Reorder list: items picked up, carried, and set down in a new order.
+ Initials stack: a few people in a row, with a count for the rest.
+ Badge: a small count that changes without shouting.
+ Sparkline: a tiny line of numbers that fits inside a sentence.
+ Undo: a mistake taken back within a few seconds.
+ Key hint: a key shown on screen that lights when it is pressed.
+ Character counter: a text box that shows how much room is left.
+ Theme switch: light and dark traded in one motion.
+ Dial: a value set by turning a knob around its edge.
+ File drop: a place to drop a file and see that it was received.
+ Scroll progress: a thin line that shows how much of a page is read.
+ Split view: two panes divided by an edge the hand can move.
+ Carousel: a few cards that move one at a time, by swipe or key.
+ Status dot: a single light that says online, busy, or away.
+ Command menu: a short list of actions found by typing a few letters.
