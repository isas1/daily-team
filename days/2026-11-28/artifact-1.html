Audiobook copy check

    About

    Ctrl+Enter in either box runs Check. Copy lists missing and partial titles, one per line. Demo data is local. Nothing is sent anywhere.

    • Technical illustrator (lead): the half-downloaded title counterexample; Copy recomputes from current boxes so it never copies a stale list.
    • Cabinet maker: boxes that keep your text, a still ledger, plain labels Held, Missing, Partial.
    • Color grading specialist: one normalization rule for both lists, with Part k of m counting.
    • Ocean station keeper: Ctrl+Enter, focus back to Library on error, a count line readable without color.
